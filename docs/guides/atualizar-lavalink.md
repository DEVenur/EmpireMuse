# Mini-Guia de como atualizar o lavalink.jar e a [source de música](https://github.com/DiscordEmpireHub/EmpireMuse)

* Nota: Relacionado ao lavalink.jar é válido apenas pra quem usa servidor lavalink **LOCAL**.

OBS: os comandos abaixo devem ser utilizados em um canal de texto no discord no qual o bot tem acesso.

Pra atualizar o Lavalink é só usar o comando abaixo mencionando o bot e reiniciar em seguida:
```py
@teubot updatell
```

Pra atualizar o code de música basta apenas usar o comando abaixo e reiniciar o bot após o processo:
```py
@teubot update
```
